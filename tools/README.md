# Інструменти збірки матеріалів

`build_materials.py` перетворює Markdown-інструкції на HTML і PDF із **кольоровими блоками**: КОПІЮЙТЕ (синій), У ЧАТ CURSOR (фіолетовий), У FIGMA MAKE (малиновий), ПЕРЕВІРТЕ (зелений), ЯКЩО НЕ ВИЙШЛО (помаранчевий), БЕЗПЕКА (червоний), здача (бірюзовий), орієнтир (сірий). Кольори задає `materials.css`.

## Потрібно

- Python 3 і пакет `markdown`: `pip install markdown`
- Google Chrome або Microsoft Edge (для PDF; на Windows знаходяться автоматично)

## Приклади

```bash
# HTML і PDF версії для учасників (розділи для викладача й ментора приховано)
python tools/build_materials.py materials/day-1/day-1-instruction.md --pdf

# версія для викладача (розділи для викладача показано)
python tools/build_materials.py materials/day-1/day-1-instruction.md --pdf --teacher

# усі дні
python tools/build_materials.py materials/day-*/day-*-instruction.md --pdf
```

Результат потрапляє в папку `build/` (її не комітимо).

## Що робить скрипт

- Блок із маркером (наприклад, `**КОПІЮЙТЕ**`, `**У ЧАТ CURSOR:**`) і наступний за ним код чи список обгортає в кольорову рамку.
- Для учасників **прибирає** розділи «Для викладача», «Критерії перевірки (ментору)» і примітку «ЧЕРНЕТКА». З ключем `--teacher` залишає їх.
- Додає легенду кольорів під заголовком.

## Обмеження

- Діаграми Mermaid не малюються: у PDF вони показуються як код.
- Колір працює лише за маркерами, що стоять на початку абзацу. Інші блоки (цитати) мають жовту рамку.
- Налаштування Moodle (як вставляти HTML чи PDF) не перевірялося.
