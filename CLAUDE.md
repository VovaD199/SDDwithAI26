# SDDwithAI26

> Ізольований проєкт. Не залежить від інших проєктів акаунта.

## Мета
Підготовка практичного курсу «Spec Driven Development with AI» для бізнес-аналітиків і PM (зовнішня аудиторія): 4 дні по 4 години, воркшоп, Moodle, покрокові інструкції. Цей репозиторій містить специфікацію, план і (далі) навчальні матеріали курсу. Не сам навчальний застосунок.

## Стек
- Документи: Markdown (українською), діаграми Mermaid.
- Інструмент курсу: Cursor; наскрізний кейс: шаблонний репозиторій lf-client (Next.js + TypeScript, MongoDB в пам'яті, Node.js 22, без Docker).
- Платформа курсу: Moodle. Git/GitHub.

## Команди
Збірки й тестів у цьому репозиторії немає (документація). Для кейсу lf-client: `npm install`, `npm run dev` (http://localhost:3000), `npm test`, `npm run typecheck`.

## Структура
- `docs/` — spec, plan, plan-detailed, decisions.
- `sources/` — вихідні матеріали (PDF, протоколи, архіви); лише локально, у `.gitignore`.

## Підхід (Spec-Driven Development)
- Вимоги: `docs/spec.md`
- Поточний план: `docs/plan.md`, деталізований для викладача: `docs/plan-detailed.md`
- Прийняті рішення: `docs/decisions.md`
- Перед змінами читай spec і plan; після суттєвих рішень оновлюй decisions.

## Правила
- Спілкуйся українською.
- Секрети лише в `.env` (він у `.gitignore`), ніколи в коді.
- Дрібні, перевірювані кроки; після кожного кроку запускай тести.
