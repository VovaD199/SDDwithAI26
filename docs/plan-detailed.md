# Деталізований план курсу (для викладача)

> ЧЕРНЕТКА v1.1. Інструкції учасників по днях: `materials/day-N/`. Курс: «Spec Driven Development with AI». 4 дні × 4 год. Інструмент: Cursor. Кейс: шаблонний репозиторій lf-client (учасники працюють у власних копіях, здають посилання на PR). Тривалості орієнтовні.

## Загальна схема кожного дня

| Блок | Хв | Що |

| Демо ведучих | 45 | Ведучий показує прийом на прикладі |

## Ризики та обхідні шляхи (описати у навчальних матеріалах)

**Токен GitHub і MCP (день 2).** MCP-сервер для курсу плануємо робити. У матеріалах описати три ризики:
1. *Безпека токена:* fine-grained PAT тільки на власний репозиторій, мінімальні права, термін 30 днів, `.cursor/mcp.json` у `.gitignore`, перевірка `git status` перед комітом, токен не вставляти в чат, відкликати після курсу.
2. *Обмеження організації:* корпоративна політика може заборонити PAT. Обхід: вправи без MCP (копіювання тексту issue в чат Cursor, результат вставляється вручну на github.com).
3. *Проблеми підключення:* червоний індикатор (пробіл у токені, прострочений токен, неправильний шлях `.cursor/mcp.json`), перелік причин і перезапуск Cursor.

**Node/Git на різних ОС (день 1).**
- Для кожної команди три блоки: Windows / macOS / Linux; для великого функціоналу окремі PDF встановлення.
- Попередня перевірка перед курсом: учасник надсилає скріншот `node -v` і `git --version`.
- Запасні варіанти: Download ZIP замість `git clone`; за потреби GitHub Codespaces (перевірити, чи це дозволено для зовнішніх учасників).

**Обсяг дня 3.** Figma розділено: Figma Make на дні 3, Figma MCP і зріз прототипу на дні 4. День 4 при цьому щільний (скорочено живий огляд), тому на прогоні перевірити хронометраж.
